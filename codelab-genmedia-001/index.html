La Filosofía: Single Source of Truth (SSoT)

El desafío más común en la producción con IA es la desalineación de estilos. Si generas la imagen con un prompt y luego el video con otro no relacionado, se pierde la coherencia de iluminación, personaje y narrativa.

SDK Oficial

Interactions API

La Nueva Arquitectura: Interactions API

Google ha presentado la Interactions API como la interfaz recomendada para interactuar con los modelos Gemini en Python y TypeScript utilizando el SDK oficial google-genai (versión ≥ 2.3.0).

warning
Aviso de Migración: Métodos antiguos como generateContent y librerías heredadas como google-generativeai están obsoletas. La nueva API unifica texto, pensamiento (Thinking), herramientas y multimodalidad en un modelo basado en Steps tipados.

Estructura de un Turno de Interacción

client.interactions.create(
    model="gemini-3.7-flash",
    input="Tu prompt o contenido multimodal..."
)

Cada respuesta contiene una lista ordenada de Steps:

  • user_input: Contenido enviado por el usuario (texto, imágenes, audio).
  • thought: Razonamiento explícito del modelo (Chain of Thought).
  • model_output: Salida final (texto, JSON, imagen o audio generado).

Código: Generación del Brief Maestro con Salida Estructurada

Utilizamos Pydantic y response_schema para asegurar que gemini-3.7-flash entregue un JSON estrictamente tipado que controlará el resto de las modalidades:

from google import genai
from pydantic import BaseModel, Field

client = genai.Client()

# Esquema de salida para orquestar la campaña
class CampaignBrief(BaseModel):
    title: str = Field(description="Título cinematográfico de la pieza")
    synopsis: str = Field(description="Sinopsis narrativa en 2 oraciones")
    visual_prompt: str = Field(description="Prompt en 5 capas para Nano Banana / Google Flow")
    voiceover_script: str = Field(description="Texto exacto de la locución en español con audio tags")
    voice_direction: str = Field(description="Estructura Voice Director: Profile, Scene, Director Notes")
    music_prompt: str = Field(description="Prompt con instrumentos, tempo y género para Lyria 3")
    video_timeline: str = Field(description="Timeline descriptiva [0-2s], [2-4s], [4-5s] para Omni")

# Llamada a la Interactions API con response_format
interaction = client.interactions.create(
    model="gemini-3.7-flash",
    input="Crea el brief cinematográfico de una guardiana glacial esculpida en hielo cristalino y escarcha.",
    response_format={
        "type": "text",
        "mime_type": "application/json",
        "schema": CampaignBrief.model_json_schema()
    }
)

print(interaction.output_text)

Modelos Visuales: Nano Banana 2 & Nano Banana Pro

Para la generación de keyframes visuales 16:9 y concept art cinematográfico, Google cuenta con dos modelos clave:

  • gemini-3.1-flash-image (Nano Banana 2): Ultrarrápido, excelente precisión en el seguimiento de instrucciones y renderizado veloz.
  • gemini-3-pro-image (Nano Banana Pro): Máxima fidelidad microtexturizada, acabados fotorrealistas y renderizado de alta resolución.

La Técnica de las 5 Capas de Prompting Visual

Para evitar imágenes genéricas o poco enfocadas, estructura siempre tus prompts en 5 capas consecutivas:

  1. Sujeto Principal: Detalles fisonómicos, materiales constitutivos, expresión, vestimenta.
  2. Acción y Pose: Ángulo de la mirada, inclinación, microgestos sutiles.
  3. Composición y Encuadre: Tipo de plano (Close-up / Primer plano), óptica de lente (85mm f/1.4), relación de aspecto 16:9.
  4. Iluminación y Color: Luz volumétrica, temperatura de color, claroscuro, destellos y reflejos cáusticos.
  5. Acabado y Textura: Nivel de detalle, microfracturas, escarcha, render fotorrealista 8k.

Gemini 3.1 Flash TTS

El Paradigma Voice Director

A diferencia de los sintetizadores de voz convencionales que solo leen texto plano o dependen de complejas etiquetas SSML, el modelo gemini-3.1-flash-tts-preview es un Large Language Model que entiende no solo qué decir, sino cómo decirlo.

El framework Voice Director te permite tratar a Gemini TTS como un actor de doblaje profesional humano, proporcionándole perfil de personaje, contexto espacial y notas directas de interpretación.

Estructura de un Prompt Voice Director

badge

1. AUDIO PROFILE

Define el nombre, rol y arquetipo del personaje. Proporciona el ancla de identidad del actor virtual.

location_on

2. THE SCENE

Establece el entorno físico, acústica del lugar y atmósfera emocional para condicionar la energía vocal.

tune

3. DIRECTOR'S NOTES

Instrucciones de interpretación: Style (textura vocal/proyección), Accent (acento específico) y Pacing (cadencia/tempo).

format_quote

4. TRANSCRIPT

El guion exacto anotado con Inline Audio Tags entre corchetes para controlar emociones y pausas momento a momento.

Inline Audio Tags: Banderas de Emoción, Gestos y Pausas

Los tags se insertan directamente en el guion en inglés (incluso con texto en español) para modelar la entonación con máxima granularidad:

🎭 Banderas de Emoción y Tono:

[serenity] [awe] [determination] [excitement] [curiosity] [confidence] [intrigue] [melancholy] [enthusiasm] [warmth]

🗣️ Acciones Vocales y Sonidos No Verbales:

[whispers] [sigh] [laughs] [chuckle] [gasp] [shouting] [clears throat]

⏱️ Control de Pausas y Ritmo:

[short pause] (~250ms) [medium pause] (~500ms) [long pause] (~1000ms+) [slow] [fast]

Composición Musical Generativa con Lyria

El modelo lyria-3-clip-preview (disponible interactivamente en MusicFX) está diseñado para componer piezas musicales y ambientaciones sonoras con riqueza tímbrica y estructura armónica.

Los 4 Pilares de un Prompt Musical

Pilar Descripción Ejemplo para Nuestro Video de Hielo
1. Género y Atmósfera Estilo principal y sensación emocional Atmospheric Nordic Neo-Classical Ambient
2. Instrumentación Instrumentos solistas y texturas de fondo Sub-bass drone, cello solista acústico, marimba de cristal, pads de escarcha
3. Tempo y Dinámica Velocidad (BPM) y evolución de intensidad 72 BPM, inicio minimalista y sutil crescendo etéreo
4. Prompts Negativos Elementos a evitar Sin batería estridente, sin guitarras eléctricas, sin voces líricas

Código: Generar Pista Musical

music_prompt = """
Atmospheric cinematic ambient score with deep sub-bass drones, crystalline glass marimba arpeggios, bowing acoustic violoncellos, and ethereal glacial pads. Tempo: 72 BPM. Mood: Mystical, serene, expansive winter landscape. Subtle sound design of frosted resonance. No heavy drums.
"""

interaction = client.interactions.create(
    model="lyria-3-clip-preview",
    input=music_prompt,
    generation_config={
        "duration_seconds": 30
    }
)

if interaction.output_audio:
    with open("media/soundtrack_artico.mp3", "wb") as f:
        f.write(interaction.output_audio.data)
    print("✓ Pista musical guardada en media/soundtrack_artico.mp3")

Gemini Omni 1.1 Flash

Multimodal Video & Swap

Gemini Omni Flash (`gemini-omni-flash-preview`)

Gemini Omni Flash es el modelo unificado de video y audio de Google. Permite generar tomas de alta calidad (3 a 10 segundos), animar imágenes fijas y realizar transformaciones de video-a-video guiadas por referencias fotográficas.

Caso 1: Animación First-Frame a partir de un Keyframe

Toma el keyframe generado por Nano Banana como fotograma de inicio exacto mediante la etiqueta <FIRST_FRAME> y timeline prompting:

uploaded_keyframe = client.files.upload(file="media/keyframe_mujer_hielo.png")

video_prompt = """
[# Sources ]
[0-2s] Extreme slow cinematic push-in toward the ice woman's face. Frost particles swirl gently.
[2-4s] Her crystal eyelashes flutter as her glowing cyan eyes shift focus.
[4-5s] A serene crystalline smile forms as ethereal light flairs gently in 16:9.
Audio: Soft arctic wind howl, delicate ice crystalline resonance, zero dialogue.
"""

interaction = client.interactions.create(
    model="gemini-omni-flash-preview",
    input=[uploaded_keyframe, video_prompt],
    generation_config={"duration_seconds": 5, "aspect_ratio": "16:9"}
)

Caso 2: Reemplazo Total de Personaje en Video (Video Propio + Foto de Referencia)

Un caso de uso sumamente potente es proporcionar un video real tuyo saludando a cámara y una fotografía de otro personaje (ej. un astronauta en Marte o una guerrera futurista). Gemini Omni Flash sustituye por completo al personaje conservando con total precisión el movimiento de la mano, la postura, los giros de cabeza y la cadencia temporal.

Estructura de Tags para Reemplazo de Personajes

Utilizamos el formato de declaración de fuentes y referencias del skill de Omni Flash:

movie_filter Prompt de Reemplazo de Personaje (Video + Imagen)
[# Sources <VIDEO_REF_0>@Video1] [# References <IMAGE_REF_0>@Image1] Replace the person in the video with the character shown in <IMAGE_REF_0>. Maintain the exact hand-waving motion, body posture, head rotation, timing, and framing from <VIDEO_REF_0>, while transforming the subject entirely into the character from <IMAGE_REF_0> (photorealistic astronaut helmet, reflective visor, spacesuit textures, and lighting). Preserve smooth temporal consistency across all frames. Keep background environment consistent.

Código: Ejecutar el Reemplazo de Personaje con el SDK

# 1. Subir ambos archivos a la Files API de Gemini
my_video = client.files.upload(file="media/mi_video_saludo.mp4")
character_photo = client.files.upload(file="media/personaje_astronauta.png")

# 2. Generar la transformación multimodal
interaction = client.interactions.create(
    model="gemini-omni-flash-preview",
    input=[
        my_video,
        character_photo,
        "[# Sources ] [# References ] Replace the person in the video with the character from . Maintain the exact wave and greeting movements, head rotation, and timing from the video, while transforming the person entirely into the character in . 16:9 widescreen, photorealistic."
    ],
    generation_config={
        "duration_seconds": 5,
        "aspect_ratio": "16:9"
    }
)

print(f"✓ Video transformado generado con ID: {interaction.id}")
