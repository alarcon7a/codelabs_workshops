Preparacion rapida

cd antigravity-cli-codelabs/docs/examples/antigravity-practice
agy

Despues de iniciar la CLI desde esa carpeta, usa este prompt para validar que el agente ve el workspace correcto:

Analiza @. y dime que archivos hay, que riesgos ves y que ejercicio recomiendas hacer primero. No edites archivos todavia.

Ejercicios incluidos

Feature Archivo Prompt sugerido
Contexto con @ src/math.js Encuentra el bug en @src/math.js y explica como lo verificarias.
Permisos de escritura src/math.js Corrige el bug minimo y ejecuta npm test.
Rules locales .agents/AGENTS.md Resume que reglas locales debes seguir en este proyecto.
Skills .agents/skills/code-reviewer/SKILL.md Usa la skill code-reviewer para revisar @src/profile.js.
MCP .agents/mcp_config.example.json Explica que servidores MCP define este archivo y que secretos faltan.
Dynamic Subagents SDK (Python) Crea un orquestador que delegue tareas a subagentes usando mode="task".
Worktree Mode settings.json Configura gitWorktreeMode y ejecuta la CLI con agy --worktree-mode.
Cross-Repo Context .agents/project.json Declara límites y alias en projectRoots para acceder a múltiples directorios.
Asynchronous Queue /schedule / /tasks Ejecuta tareas en segundo plano usando la cola asíncrona de Antigravity.

Flujo recomendado

Primero pide analisis sin editar, despues plan, luego aprueba permisos acotados y cierra con validacion. El objetivo del taller es que cada permiso tenga una intencion clara.
