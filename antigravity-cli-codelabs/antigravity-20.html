🎯 Objetivo: entender qué cambia al pasar de una CLI conversacional a una plataforma multiagente con artifacts y validación.

Antigravity 2.0 es un módulo separado porque no se limita a la terminal. Su foco es una plataforma agent-first para coordinar agentes, revisar artifacts, validar en navegador y extender workflows con plugins y SDK.

Diferencia principal

En el codelab inicial usaste una CLI interactiva. En 2.0 el trabajo se organiza como tareas agentic observables: cada agente puede tener un rol, producir artifacts y dejar evidencia de avance o validación.

Positive : Piensa en 2.0 como una capa de coordinación: CLI, app de escritorio, manager visual, plugins y workflows comparten una forma común de trabajar con agentes.

🔍 Checkpoint: estás listo cuando puedes explicar en una frase la diferencia entre un prompt en la CLI y una tarea agentic con artifacts.

🎯 Objetivo: reconocer las piezas de la plataforma (Agent Manager, artifacts, browser validation, SDK, plugins, subagentes) y para qué sirve cada una.

Features concretas de Antigravity 2.0

Herramienta Qué permite hacer
Agent Manager Lanzar, observar y coordinar varios agentes en paralelo. Úsalo para separar análisis, implementación, pruebas, documentación y revisión de seguridad.
Desktop app Centraliza sesiones, workspaces, artifacts y estado de agentes. Es el lugar natural para monitorear trabajos largos que en terminal serían difíciles de seguir.
Artifacts verificables Registra planes, checklists, screenshots, browser recordings, resultados de pruebas y decisiones técnicas. Sirven para revisar intención y evidencia, no solo el texto final del agente.
Browser validation Permite que el agente abra una app, recorra flujos de usuario, capture pantallas y grabe evidencia visual para validar cambios de frontend.
SDK Permite crear workflows propios alrededor de agentes: iniciar tareas, conectar herramientas internas, definir pasos de revisión y producir artifacts personalizados.
Plugins Agrupan extensiones, skills, hooks, subagentes e integraciones en paquetes reutilizables para equipos o proyectos.
Subagentes Dividen una tarea compleja en agentes especializados. Por ejemplo: uno inspecciona arquitectura, otro modifica código y otro valida regresiones.
Backend unificado Busca que CLI, app, plugins y agentes compartan más contexto y capacidades, reduciendo saltos entre herramientas separadas.

🎯 Objetivo: identificar escenarios reales donde coordinar varios agentes aporta más que un solo prompt en la terminal.

Dónde 2.0 aporta más que la CLI

  • Refactor grande: un agente prepara el plan, otro toca módulos, otro corre pruebas y otro redacta el resumen de revisión.
  • Frontend con evidencia: el agente implementa, abre navegador, captura screenshots y deja un browser recording como artifact.
  • Release checklist: varios agentes validan tests, documentación, migraciones, changelog y riesgos antes de entregar.
  • Onboarding de repo: un agente explora arquitectura, otro genera mapa de módulos y otro prepara tareas iniciales para nuevos contributors.
  • Automatización de equipo: plugins y SDK empaquetan políticas internas, revisiones obligatorias y herramientas privadas.

Prompt recomendado para 2.0

👉 Copia y pega este prompt en un entorno con Antigravity 2.0:

Trabaja como plataforma multiagente.
Agente 1: analiza arquitectura y riesgos.
Agente 2: implementa el cambio mínimo.
Agente 3: valida con tests y navegador.
Agente 4: prepara artifacts de revisión.
Entrega: plan, diff resumido, resultados de pruebas, screenshots o browser recording, y riesgos pendientes.

✅ Resultado esperado: en lugar de una respuesta de texto, obtienes entregables revisables (plan, diff, resultados de pruebas y evidencia visual) asociados a la tarea.

🔍 Checkpoint: estás listo cuando puedes describir qué agente hace qué y qué artifact deja cada uno como evidencia.

Negative : No asumas paridad exacta entre Gemini CLI, Antigravity CLI y Antigravity 2.0. Antes de un taller o migración de equipo, valida qué versión está instalada y qué herramientas están habilitadas: Agent Manager, browser validation, plugins, subagentes, SDK y artifacts.
